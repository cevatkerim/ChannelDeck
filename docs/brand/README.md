# ChannelDeck identity

Two overlapping screens make a deck; a softened play symbol keeps the purpose clear at a glance. The Dock icon uses mint layers against deep forest green. Inside the app, the same geometry becomes a single-color vector symbol that follows light and dark appearance.

The original artwork is reproducible with `swift Scripts/render-brand.swift` from the repository root. The script exports every macOS icon size, About artwork, and a template PDF for the interface. `channeldeck-icon.png` is the full-size master preview. No fonts or external artwork are required.
