# ChannelDeck 0.2.1 — Better starts, better guides

Faster local viewing, more reliable first pictures, uninterrupted playback while browsing the guide, and opt-in Open-EPG listings. App version **0.2.1**, build **3**.

## What's new

- **Local playback first.** Start watching once the first validated segment is ready while the larger AirPlay buffer prepares in the background. Enabling AirPlay keeps the same player item, paused position, live buffer, and active recording.
- **Black-screen startup fixes.** Some H.264 feeds begin without an independently decodable picture. ChannelDeck detects this before publishing the stream and retries with compatibility conversion. Loading feedback now waits for a real video frame, not just an advancing audio clock; a missing picture produces an actionable retry message. Original Video recording still preserves the source video.
- **Keep watching while browsing.** Opening the TV guide preserves the native video surface and playback. Returning to the player no longer requires scrubbing to restore the picture.
- **Less work on the UI thread at launch.** Catalogue reads and sorting run in the background, with batched restoration for large libraries.
- **Opt-in Open-EPG integration.** Choose Automatic or Open-EPG in a playlist's **Edit → Programme guide** settings. Discover relevant country guides, review uncertain matches, and save manual corrections. Movies and series are excluded. Existing playlists keep their current guide provider until you opt in.
- **Clearer guide updates.** Changing guide settings no longer reimports the entire channel library. The editor closes after saving, with progress beneath the playlist heading during downloading, matching, and listing import. Country feeds use a shared daily cache; unavailable or stale feeds are reported without discarding working listings.

## Download and install

Download **ChannelDeck-0.2.1-arm64.dmg** below. Requires an **Apple Silicon Mac running macOS 15 or newer**. The standalone LGPL FFmpeg 8.0.1 helper is included; Xcode and Homebrew are not required.

This is a **testing prerelease with an ad hoc signature, without Developer ID signing or Apple notarization**. The signature supports integrity checks, not Apple-verified developer identity.

1. Quit any older running copy of ChannelDeck when you are ready to update.
2. Open the DMG and drag ChannelDeck into Applications, replacing the previous app if installed.
3. Eject the image and open ChannelDeck from Applications. Updating the app does not remove your library, recordings, or Keychain credentials.
4. If macOS blocks the app and you trust this download, use **System Settings → Privacy & Security → Open Anyway**, then confirm. Managed Macs may prohibit this exception. See [Apple's instructions](https://support.apple.com/en-us/102445).

No channels, playlists, subscriptions, or credentials are included. Add a playlist you are authorized to use. Open-EPG matching stays on your Mac; playlist credentials and channel lists are not sent to that provider.

## Verification and limitations

- The playback changes ran **215 XCTest cases: 213 passed, two opt-in live-service tests skipped, and zero failures**. All **three Swift Testing checks** also passed.
- Real synthetic-video tests confirmed that clean and open-GOP streams display their first picture without seeking, before the AirPlay buffer is ready. They also checked original recording bytes and playback across guide navigation.
- The optimized arm64 Release build, DMG integrity, version/build numbers, nested ad hoc signatures, and system-library dependencies passed verification. The mounted image's bundled FFmpeg passed synthetic open-GOP conversion and decode checks with a minimal environment. The packaged app was not relaunched during this release pass, to leave an existing viewing session uninterrupted.
- Open-EPG coverage depends on the provider. Some countries or channels have no published feed or no current listings; ambiguous matches require review.
- Raw transport streams still need packaging, and some need conversion. Startup speed depends on provider data and keyframes. An initial conversion retry may reconnect to the provider before playback starts; preparing AirPlay afterwards does not open another connection.
- Secure AirPlay requires relay configuration and a working local network. Rewind and recording require an available live buffer; available disk space, stream continuity, and the Mac remaining awake still apply.
- This artifact does not support Intel Macs. Installation on a separate clean Mac remains to be verified.
