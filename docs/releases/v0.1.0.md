# ChannelDeck 0.1.0 — First testing release

A native macOS IPTV player with global channel search, live TV rewind, original-quality recording, and AirPlay.

## Download and install

Download **ChannelDeck-0.1.0-arm64.dmg** from the assets below. Requires **Apple Silicon and macOS 15 or newer**. FFmpeg is included; Homebrew and Xcode are not required.

This testing build is **not Developer ID signed or notarized**. It has an ad hoc integrity signature, which does not establish developer identity with Apple.

1. Open the DMG and drag ChannelDeck into Applications.
2. Eject the DMG and open ChannelDeck from Applications.
3. If macOS blocks it and you trust this release, use **System Settings → Privacy & Security → Open Anyway**, then confirm. Managed Macs may prohibit this exception. See [Apple's instructions](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac).
4. Add your own authorized M3U playlist. No channels, subscriptions, or credentials are included.

## Included

- Multiple playlists, global channel search, groups, favorites, and recently watched channels.
- XMLTV current/next programme information and cached channel logos.
- Native playback, fullscreen, Picture in Picture, and optional secure AirPlay relay.
- Rolling live rewind and jump-to-live controls on the compatibility pipeline.
- Save Buffer adopts available history and continues recording until stopped or the channel changes.
- Original-video and compatible recording choices, thumbnails, guide metadata, and Show in Finder.
- Video-only stream handling, branded loading screen, and About links.
- Standalone LGPL FFmpeg 8.0.1, built from pinned source using Apple system libraries.

## Notes and verification

- Intel Macs are not supported by this artifact.
- Secure AirPlay relay configuration still requires your Cloudflare zone/token and a working local network; see the README.
- Original Video preserves source video; audio is converted to AAC. The compatibility rendition can convert UHD/HEVC to H.264 at up to 1080p.
- Recording duration is not capped by the app; disk space and stream continuity still apply.
- Release compilation, DMG integrity, nested ad hoc signatures, arm64 architecture, and bundled dependencies were checked. Synthetic H.264/AAC and HEVC-to-H.264/AAC media checks passed. The FFmpeg helper also ran directly from the mounted image with a minimal environment.
- Installation and end-to-end playback on a separate clean Mac remain to be verified.
