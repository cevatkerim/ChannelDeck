# ChannelDeck 0.2.0 — A closer look at live TV

A redesigned native Mac TV library, an original mint and forest identity, and a searchable TV guide built for large channel collections. App version **0.2.0**, build **2**.

![ChannelDeck live playback and redesigned library](https://github.com/cevatkerim/ChannelDeck/blob/v0.2.0/docs/screenshots/playback.jpg?raw=true)

## What's new

- **A new look throughout.** Original app icon and vector interface symbol, coordinated light and dark appearances, a branded sidebar, and refined player, playlist, settings, and empty states.
- **A full-width TV guide.** Browse two-hour timeline pages, filter by favorites or playlist, search channels and programmes, and open programme details to watch live.
- **Responsive guide search.** Reusable search snapshots, background matching, brief input debouncing, and cancellation of superseded queries keep large EPG searches away from the main UI thread. Tests cover 60,000 channels and 360,000 programmes.
- **A library that fits you.** Hide or restore playlist groups, filter long group lists, arrange favorites, and choose comfortable or compact reading density. Preferences persist between launches.
- **Clearer playback and recording.** Immediate connection progress, cancel and retry actions, inline playlist recovery, a Record / Stop recording control, elapsed recording time, and available disk space.
- **Playback switching fixes.** Choosing another channel or recording replaces the previous playback target, including while a stream is preparing. Playlist refresh and removal also avoid repeated full-library scans.
- **Updated documentation.** Six current screenshots, keyboard shortcuts, guide and library instructions, and reproducible brand artwork.

## Download and install

Download **ChannelDeck-0.2.0-arm64.dmg** from the release assets. Requires **Apple Silicon and macOS 15 or newer**. The standalone LGPL FFmpeg 8.0.1 helper is included; Homebrew and Xcode are not required.

This is a **testing prerelease**, without Developer ID signing or Apple notarization. Its ad hoc signature checks bundle integrity but does not establish developer identity with Apple.

1. Quit an older running copy of ChannelDeck.
2. Open the DMG and drag ChannelDeck into Applications, replacing the previous app if installed.
3. Eject the image and open ChannelDeck from Applications. Existing library data remains in Application Support and credentials remain in Keychain.
4. If macOS blocks the app and you trust this release, use **System Settings → Privacy & Security → Open Anyway**, then confirm. Managed Macs may prohibit this exception. See [Apple's instructions](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac).

## Verification and limitations

- The redesign passed 165 XCTest cases with two opt-in live-service skips and zero failures, plus three Swift Testing checks.
- Native guide browsing, light and dark appearance, recording playback, and switching between live channels and recordings were exercised on the development Mac.
- The optimized arm64 Release build, DMG integrity, bundled version/build numbers, nested ad hoc signatures, and system-only dependencies passed verification. The mounted app launched, its About panel reported 0.2.0 (2), and live playback was verified using the bundled helper.
- Bundled FFmpeg passed H.264/AAC encode/decode and video-only HEVC-to-H.264/AAC conversion checks from the mounted image with a minimal environment.
- Intel Macs are not supported by this artifact. Installation and playback on a separate clean Mac remain to be verified.
- Secure AirPlay still requires relay configuration and a working local network. Live rewind and recording depend on a channel having an available live buffer. Recording length depends on disk space, stream continuity, and the Mac remaining awake.
